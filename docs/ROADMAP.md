# Roadmap

## python-v0.1 - Archived Baseline

- Python FastMCP prototype
- User, group, and direct mutation tools
- Cloud Run and Terraform experiments

Preserved as repository history and the `python-v0.1` tag. It is not the supported runtime.

## v0.2 - Scoped Local Investigation

- TypeScript MCP 2026/2025 stdio negotiation
- Restricted profile-based discovery
- Effective internal-to-Google scope derivation
- Exact user and membership inspection
- Subject-scoped Admin audit search with bounded windows
- Structured pagination and completeness markers
- Deterministic privileged-user review
- Content-free OpenTelemetry spans through the Google adapter
- Provider mapping, policy, trace, and redaction tests

## v0.3 - Remote Enterprise Runtime

- MCP 2026-07-28 stateless HTTP handler
- OAuth protected-resource metadata
- issuer, audience/resource, expiry, tenant, and scope validation
- per-request principal-aware tool discovery and invocation policy
- gateway routing, rate limits, and coarse authorization
- separate Google workload, delegated, or on-behalf-of credentials
- bounded retries, deadlines, and typed provider errors
- durable audit and idempotency records
- container deployment and infrastructure examples

## v0.4 - Approval-Gated Membership Changes

- inspect current membership
- propose an immutable structured diff
- evaluate deterministic policy
- bind human approval to the exact diff hash
- execute once using an idempotency key
- verify resulting state
- attach evidence to the operation trace and audit record

## v1.0 - End-to-End Enterprise Demonstration

- authenticated remote client
- one trace across agent, model, gateway, MCP, policy, and Google
- privileged-user investigation workflow
- approval-gated group membership change
- deployment and incident-response runbooks
